# 🎬 GETTING STARTED - Bắt Đầu Ngay!

**Chào mừng đến với Everything Downloader!**

Hướng dẫn này sẽ giúp bạn bắt đầu trong **30 giây**.

---

## ⚡ 30 Giây Để Bắt Đầu

### **Option 1: Chạy File EXE (Dễ Nhất)**

```
1. Tìm file: everything_downloader.exe
2. Double-click
3. XONG! ✅
```

### **Option 2: Chạy Từ Python (Cần Python)**

```bash
# 1. Cài dependencies (lần đầu)
pip install -r requirements.txt

# 2. Chạy
python everything_downloader.py

# XONG! ✅
```

## 🎯 Cách Sử Dụng (3 Bước)

```
1️⃣ Paste URL
   Copy-paste link từ YouTube hoặc Facebook

2️⃣ Click Download
   Hoặc nhấn Enter

3️⃣ Chờ & Tìm Video
   Video sẽ lưu trong thư mục "videos/"
```

